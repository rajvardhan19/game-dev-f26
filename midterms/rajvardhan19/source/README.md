# Original source, unmodified

`CWSTRAT.BAS` and `VariablesGuide.md` are byte-for-byte copies from
[rajvardhan19/Mod-Civil-War-Strategy-Game](https://github.com/rajvardhan19/Mod-Civil-War-Strategy-Game)
at commit `dac8db1` (v2.11), a fork of
[historicalsource/Civil-War-Strategy-Game](https://github.com/historicalsource/Civil-War-Strategy-Game).
`VariablesGuide.md` is `component-parts/VariablesGuide.md` there.

- Game: VGA Civil War Strategy by W. R. Hutsell (1998); QB64 port and
  v2.11 by Dave Mackey (2017-2018).
- Licence: MIT, (c) 2018 Dave Mackey; see `LICENSE` in this folder.
- SHA-256 of `CWSTRAT.BAS`: `9437948fe1b013d6968f91e3bf247ac05534bb40dd1952a65fc63a6ecf549f7a`.

Every `line N` citation in this project refers to this file. The data files
the game reads (`CITIES.GRD`, `CWS.INI`, `CWSLEAD.DAT`, `CWS.CFG` and the
`ALTMAP` set) are in `../data/original/`, also unmodified.
